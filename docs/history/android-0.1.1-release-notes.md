# lark Android 0.1.1

首发之后连着用了一天，列回来十一条。**只有一条是 bug**（锁屏播完不续播），其余是产品形状——这一版把十一条都改了，外加后来补上的一条：**车机和耳机现在能切歌**。

**装**：下载 `lark-0.1.1.apk` 点开安装，**直接覆盖 0.1.0，曲库不动**（签名相同）。需要 Android 8.0 以上。
**只在这里发，不进应用商店，没有自动更新。** 桌面版不跟着发，仍是 0.4.0。

## 修好的那一条

- 🔴 **熄屏播完一首，现在会自动播下一首。** 以前要等约一分钟，而且得解锁才动。取证下来判断和播放一直都是对的，卡住的是链路中间一个 JS 定时器——熄屏时它被系统冻住，解锁才解冻。已经换成原生实现，锁着屏也照走。

## 车机、耳机、通知栏

- 🔴 **上一首 / 下一首现在能用了。** 车机、耳机按键、锁屏和通知栏都可以切歌——首发时这四个地方只有播放/暂停和 ±10s。（不是漏接线：播放库把曲目导航的命令明确删掉了，lark 打了补丁加回来，而下一首是谁仍然由 app 自己的队列说了算。）
- 通知栏折叠时是 **上一首 ｜ 播放/暂停 ｜ 下一首**，展开还多 ±10s 两个。
- 一个值得知道的既有规则：**在最后一首按「下一首」会回到第一首**——按钮是一个意图；而一首歌自然播完走到列表末尾则停下。

## 下载

- **下载记录留得住了。** 完成过的下载写进文件，从最近任务里划掉进程、重开也还在（保留最近 200 条）。失败和取消的行上有「重下」，成功的行没有——重新下载一首已经有的歌，在「歌曲」里点它的 ⋮。
- **失败会自动重试**，默认 1 次，设置里可以改成 0 / 1 / 2 / 3。只重试「再试一次可能不一样」的失败：连接失败、超时、B 站接口出错、转码失败。风控和 LLM 出错不重试——再问一次正是它出现的原因。顺带修好一件事：**下载超时以前报的是「内部错误」**，现在说的是超时。
- **歌单可以「全部下载」**，在歌单详情页。
- **缓存上限现在是一道门**：自动下载排到上限就停，**不会替你删旧文件**。停下的每一首在记录里留一行，写清楚是上限拦的；想要它就点那一行的「重下」（那会按最近最少使用清理旧文件），或者把上限调高。「下新删旧」始终是一个人的决定。
- **自动下载下一首**（默认开，设置里可关）：顺序播到一首没有文件的歌，会**去取回来再播**，而不是跳过它；而且在上一首还放着的时候就开始取，通常听不出停顿。随机播放和单曲循环不预取。

## 界面

- 顶上的「lark」那一栏去掉了，每屏多一行内容。
- **返回键按层退**：先退出多选 → 再退出歌单 → 再回到「歌曲」→ 才退到后台。
- **添加页整页一个滚动条**：表单和长长的任务列表一起滚，而且**打字时键盘不会掉**。
- 歌单里点一首歌的 ⋮，和「歌曲」页是同一张菜单了（多一条「移出歌单」）。**红色只留给「删除」**。
- 设置页收干净了：删掉八项调试信息，留下「曲库 N 首」和折叠起来的「最近的错误」。
