# lark Android 0.1.0（首发）

lark 的手机端。同一个曲库：播放、从 bilibili 下载、自动配歌词、歌单，以及与桌面之间的同步。

**装**：下载 `lark-0.1.0.apk` 点开安装（系统会提示「来自未知来源」，允许一次即可）。需要 Android 8.0 以上。
**只在这里发，不进应用商店，没有自动更新。**

## 有什么

- **播放器**：队列、四种播放模式、进度记忆、锁屏与通知栏、蓝牙断连自动暂停。
- **下载**：粘一个 bilibili 链接，或者直接按歌名搜；收藏夹和合集可以整批展开勾选；多行粘贴一次提交；从别的 app 分享过来也行。可选**清洗命名**（让 LLM 从视频标题里读出歌名与歌手）。
- **同步**：登录 skybridge 账号之后，曲目信息、歌单、歌词跨设备同步。
- **歌单**：导入桌面导出的文件，也能导出给桌面。
- **缓存**：设了上限之后自动清理下载来的音频；导入的文件永不自动删。

## 要知道的几件事

- **和桌面是两台设备，不是主从。** **音频本体不同步**——别的设备加的歌在这里显示「需要下载」，点播放时再去取。
- **一台手机可以有多个曲库。** 没登录的叫「本机曲库」，每个登录过的账号各有一个，互相看不见。切换曲库、或首次登录一个账号，**lark 会自己关闭一次**，重新打开就在新的曲库里。
- **数据在应用私有目录，卸载会一起删掉。** 想留退路，在歌单页把曲库导出成文件——导出的是曲目清单不含音频，导回来会重新下载。
- **清洗命名用的 LLM 只能在手机设置页里填**，存这台设备：不从桌面导入，也不参与同步。
- **同步只在前台跑**：app 在后台时收不到别的设备的改动，回到前台会补一轮。

## 与桌面的已知差异

- **锁屏和车机上只有播放 / 暂停 / 进度**——上一首、下一首在当前 Expo 版本上拿不到（系统会把这四个曲目导航命令去掉）。
- **播放队列是按下播放那一刻的快照**：之后改列表不影响正在放的这一轮。
- 蓝牙歌词（把当前歌词行送到车机显示）**只有 Android 有**。

## 验收

在一台冻结设备（vivo V2408A / Android 15）上按里程碑逐批跑，全部为 release 构建。APK 用 lark 自己的 release key 签名，签名在构建流程里当场校验。
