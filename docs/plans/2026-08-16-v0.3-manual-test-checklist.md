## §2 T5.1 命名（判据 23–28）

> 这台机器的 LLM 是配好的（`deepseek-v4-flash`），所以「清洗命名」应该是**可选中**的。

- [ ] **2.1（判据 24）· 单链接弹框**：顶栏粘一个 bilibili 视频链接 → 回车 → 弹出「**怎么命名？**」，两个选项：**原标题** / **清洗命名**。选「原标题」→ 曲库里的歌名 = 视频标题、歌手 = UP 主名
- [ ] **2.2（判据 24）· 另一个选择真的走另一条路**：换**另一个**视频链接 → 这次选「清洗命名」→ 下载过程中状态行出现过「**清洗命名**」这个阶段，落库的歌名/歌手是被拆过的（不是整条标题）
- [ ] **2.3（§4-e）· 记忆上次选择**：再粘一个链接 → 弹框默认高亮的是**你上次选的那个**，但**仍然每次都问**
- [ ] **2.4（判据 23）· 批量勾选两分支**：粘一个**收藏夹或合集**链接 → 批量选择框里勾几项 → 里面有「原标题 / 清洗命名」的选择 → 提交时**只弹一次**框；两种模式产出的名字看得出区别
- [ ] **2.5（判据 26）· 策略冲突被拒**：对**同一个视频**先用「原标题」下一遍，等它下完；再用「清洗命名」下同一个链接 → **报错拒绝**（`NAMING_MODE_CONFLICT`，文案大意「这个视频已经在库里，命名方式不同」），**不会**产出第二首歌
- [ ] **2.6（判据 25）· 歌手缺失回退**：2.2 里如果模型没读出歌手，歌手应该是 **UP 主名**而不是空
- [ ] **2.7（判据 28）· 没有 LLM 时灰显**：设置 → 通用 → 把 **API Key 清空**并保存 → 再粘一个链接 → 弹框里「清洗命名」**灰掉且不可选**，下面写着「没有配置 LLM，暂时只能用原标题」。**测完把 Key 填回去**（我会在清理阶段把副本删掉，真库的 config 不受影响）

## §4 T5.3 下载面板与全部取消（判据 30）

- [ ] **4.1 · 面板三段**：点顶栏的下载入口，打开的是一个**面板**（不是小气泡），分「**进行中 / 排队中 / 已结束**」三段
- [ ] **4.2 · 两个术语**：面板上的操作只有「**取消任务**」和「**清除记录**」——不能有「删除歌曲」。「清除记录」清掉的是**这个窗口的列表**，不是 daemon 的账
- [ ] **4.3 · 单个取消**：一次丢进去 3–4 个链接，取消其中一个**排队中**的 → 它当场变「已取消」
- [ ] **4.4（§4-f）· 全部取消**：再丢一批，点「全部取消」→ toast **逐项报结果**，而且三种结果说的是三件事：排队的当场停 / 运行中的是「已请求」/ **已经过了提交点的取消不了**（那是一首下完的歌，不是抗命）

## §5 T5b：修的是「保存了但没人接手」（判据 35–47）

### 5.1 设置页

- [ ] **5.1.1（判据 39 / F5）· 「跟随 aviary」是一个真选项**：设置 → 通用 → LLM → **接口格式**下拉里第一项是「**跟随 aviary（当前：openai）**」；选它保存、关掉设置再打开，**它还在**（0.2.x 会显示成 `openai` 并且选一次就回不去）
- [ ] **5.1.2（F6）· 清掉 Key 之后占位符说实话**：把 API Key 清空保存 → 输入框占位符是「**未设置（将回退 aviary 共享配置）**」，不是干巴巴的「未设置」
- [ ] **5.1.3（判据 41 / F7）· 缓存上限调小不用重启**：把**缓存上限**改成 **128 MB** 保存 → 设置页不报错、「存储」区块的数字照常刷新
  > 这条只能看到一半：这个库的音频总共约 50 MB，而下拉里最小的非零档是 128 MB，**调小之后没有超出上限，也就没有东西该被清掉**。「变小就排一次清理」那一半由我在 daemon 日志里核（判据 41 的单测已经覆盖触发本身）。


- [ ] **5.1.4（判据 38 / F4）· 两个入口落对房间**：先把设置关掉。点顶栏同步徽章 → popover 里的「**同步设置…**」→ 设置窗口打开时**直接停在「同步」tab**（不是「通用」）。同理，未登录时那个「**去登录…**」也落到同步 tab

### 5.2 歌词

- [ ] **5.2.1（判据 42 / F8）· 偏移 badge 归零就消失**：播一首**有歌词**的歌 → 打开歌词面板 → 点几下「歌词后移/前移」→ 出现偏移角标（如 `+1.5s`）→ 再点回 **0** → **角标消失**（0.2.x 会卡在那儿显示 `+0.0s`）
- [ ] **5.2.2 · 字号 hint**：设置里歌词字号那一项下面有一句说明，说清它**只作用于当前行且有上限**（这是有意设计，不是 bug）

### 5.3 右键菜单（判据 47 / F17）

- [ ] **5.3.1 · 菜单文案带数量**：按住 ⌘ 选中 **3 首** → 右键 → 「重新下载 **3 首**」「重新下载歌词 **3 首**」「删除歌词 **3 首**」（0.2.x 这三项没有数量后缀，而且只作用于你右键的那一行）
- [ ] **5.3.2 · 真的作用于 3 首**：选 3 首 →「重新下载歌词 3 首」→ 下载面板里**进来 3 个任务**（不是 1 个）
- [ ] **5.3.3 · 删除歌词也是 3 首**：选 3 首（挑有歌词的）→「删除歌词 3 首」→ 这 3 首的歌词都没了
